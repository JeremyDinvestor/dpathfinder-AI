# DPathfinder AI

An AI Agent Platform: a Business Operations Agent (customers, orders, reports) powered by Google Gemini tool calling, with isolated workspaces, a public demo, and a developer API secured by API keys.

```
dpathfinder-ai/
├── backend/    <- Express + MongoDB + Gemini API (this phase)
└── frontend/   <- Vite app (added later, deployed on Netlify)
```

Start in [`backend/README.md`](backend/README.md).

Deployment plan: backend on Render (Root Directory `backend`), frontend on Netlify (Base directory `frontend`).
